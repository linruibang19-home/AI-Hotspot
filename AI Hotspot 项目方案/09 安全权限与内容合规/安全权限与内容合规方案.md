# AI Hotspot 安全、权限与内容合规方案

> 文档状态：M0 冻结候选；正式公开运营前仍需结合部署地区完成法律与备案评估。

## 1. 身份与权限

MVP 关闭自由注册；管理员建号或邀请码注册。角色 USER、EDITOR、OPERATOR、ADMIN，通过细粒度 permission 执行。会话使用 HttpOnly、Secure、SameSite Cookie；登录、邀请码、重置和敏感管理操作限流。管理员建议启用 MFA，生产必须提供恢复流程。

对象级权限由资源归属、数据集 ACL、visibility 和角色共同决定。返回 404 隐藏无权私有对象；审计日志对普通用户不可见。Agent 和 RAG 继承权限且在每次检索/工具执行时复核。

## 2. 密钥与配置

DeepSeek、SMTP、MinIO 等密钥不进 Git、数据库明文、日志或消息。开发用 `.env`（仅模板入库），生产用受限 secret 文件/环境注入，数据库只存 `credentialRef` 或加密密文。支持轮换、吊销和最小权限账号。

## 3. 采集安全

- URL 只允许 http/https；解析 DNS 后阻止环回、链路本地、私网、云元数据和保留地址，重定向每跳复核。
- 限制响应大小、时间、重定向数、MIME 和解压比例；解析器在隔离 Worker 中运行。
- 尊重 robots/站点条款和合理频率；使用明确 User-Agent 和联系信息。
- HTML 消毒，禁止脚本、事件属性、危险 URL；文件下载进行类型和恶意内容检查。
- 不采集 X、微信公众号、登录内容、付费墙和明确受限内容。

## 4. 展示与索引政策

`display_policy` 决定 FULLTEXT_ALLOWED/SUMMARY_ONLY/LINK_ONLY/HIDDEN；`index_policy` 独立决定 PUBLIC_RAG/PRIVATE_RAG/METADATA_ONLY/NO_INDEX。付费墙、登录和受限内容不保存全文、不切片、不向量化；PRIVATE_RAG 仅管理员确认有权上传的内容。

公开内容保留来源、原文链接、时间和事实标记；摘要避免替代原文的过度复制。纠错与下架入口在详情页可见；管理员可紧急下架、恢复并留下审计。

## 5. Web/API 防护

CSRF 防护、严格 CORS、安全响应头、内容安全策略、上传白名单、参数 Schema、SQL 参数化、XSS 消毒、对象级授权和速率限制。公开搜索、反馈、邀请和登录单独限流；管理接口禁止跨域公开。

Nginx 配置 HTTPS、HSTS（验证后开启）、请求体限制、超时和真实客户端 IP 信任边界。RabbitMQ/MinIO/Postgres/Redis 不暴露公网。

## 6. 审计与事件响应

登录、角色、信源、发布、下架、恢复、模型 Prompt、审批、死信重放、密钥配置变更均审计。日志含 actor、动作、对象、前后差异摘要、request/correlation/trace ID，不保存密钥和不必要正文。

严重事件流程：发现 → 限制影响 → 保存证据 → 修复/轮换 → 数据与索引清理 → 通知负责人 → 复盘。备份恢复不能把已删除/下架内容重新公开，恢复后执行状态与索引对账。

## 7. 安全验收

- SSRF 私网/重定向/IPv6 绕过用例全部拒绝。
- 游客与普通用户不能读取管理、候选、私有或他人数据。
- CSP/XSS/CSRF、对象越权和批量接口权限有自动化测试。
- Git 历史、镜像层、日志、消息、错误响应无密钥。
- 退订立即生效；删除/下架同步清理公开缓存与索引。
