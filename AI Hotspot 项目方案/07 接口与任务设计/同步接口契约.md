# AI Hotspot 同步接口契约

> 文档状态：M0 冻结候选；REST `/api/v1`，OpenAPI 为实现期单一机器可读契约。

## 1. 通用约定

JSON 使用 camelCase；时间 ISO-8601 UTC；ID 为不透明 UUID；写请求支持 `Idempotency-Key`；可变对象写入携带 `If-Match` 或 `expectedVersion`。响应带 `requestId`、必要时带 `jobId`。分页使用 `cursor` 与 `limit`（默认 20，最大 100）。

错误格式：

```json
{
  "type": "https://aihotspot.local/problems/version-conflict",
  "title": "对象已被更新",
  "status": 409,
  "code": "VERSION_CONFLICT",
  "detail": "请刷新后重试",
  "requestId": "uuid",
  "fieldErrors": []
}
```

## 2. 公开 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/featured` | 日期、分类、关键词；精选与热点 |
| GET | `/contents` | 公开动态游标列表 |
| GET | `/contents/{id}` | 公开内容详情，策略化正文 |
| GET | `/events/{id}` | 公开事件与时间线 |
| GET | `/reports`、`/reports/{slug}` | 已发布报告 |
| GET | `/topics`、`/topics/{slug}` | 主题列表/详情 |
| GET | `/search` | 公开全文搜索 |

服务器强制公开过滤；客户端不能通过查询参数请求候选池。

## 3. 认证与个人 API

| 方法 | 路径 | 权限 |
|---|---|---|
| POST | `/auth/invitations/{token}/register` | 有效邀请码 |
| POST/DELETE | `/favorites/{targetType}/{targetId}` | 登录 |
| GET/POST | `/subscriptions` | 本人 |
| PATCH | `/subscriptions/{id}` | 本人 + version |
| POST | `/subscriptions/{id}/unsubscribe` | 本人/有效 token |
| GET | `/email-deliveries` | 本人 |
| POST | `/research/questions` | 登录 |
| GET | `/research/runs/{id}` | 本人或有权 |
| POST | `/agent/runs` | 登录 + 工具权限 |
| POST | `/agent/runs/{id}/cancel` | 发起人/运营 |
| POST | `/approvals/{id}/decision` | 指定审批人 |
| POST | `/feedback` | 游客可提交，限流 |

研究创建返回 202 和 Job；答案事件通过 SSE 提供。Agent 创建体包含目标、上下文对象和允许工具，不接受任意系统 Prompt。

## 4. 管理 API

- `/admin/sources`、`/admin/endpoints`：ADMIN/OPERATOR 写；支持 probe、activate、pause。
- `/admin/fetch-jobs`：查看、取消、受控重试、死信重放。
- `/admin/contents/{id}/publish|unpublish|restore`：需要原因和 expectedVersion。
- `/admin/events/{id}/members|merge|split|relations`：事件治理。
- `/admin/reports/{id}/generate|publish|withdraw`：报告发布。
- `/admin/users`、`/admin/invitations`、`/admin/roles`：ADMIN。
- `/admin/model-routes`、`/admin/prompt-versions`：ADMIN；发布前要求评测结果。
- `/admin/feedback-tickets/{id}`：工单处理、下架和恢复。

批量端点最大 100 个对象，逐项返回成功/失败，不隐式部分成功。

## 5. SSE 事件

`GET /research/runs/{id}/events` 与 `/agent/runs/{id}/events` 使用 `text/event-stream`。事件包含递增 `sequence`、`event`、`occurredAt` 和 payload；客户端通过 `Last-Event-ID` 续传。事件类型：`status`、`step`、`citation`、`answerDelta`、`approvalRequired`、`completed`、`failed`。SSE 只推送当前用户有权运行。

## 6. HTTP 状态与缓存

- 200 查询/幂等重复；201 同步创建；202 异步接受；204 删除幂等成功。
- 401 未认证，403 无权限，404 不泄露私有对象，409 版本/业务冲突，410 已公开后下架，422 字段或状态校验，429 限流。
- 公开列表短缓存并带 ETag；个人、管理、RAG、Agent `private,no-store`；发布/下架触发缓存标签失效。

## 7. 契约验收

OpenAPI lint 通过；前后端类型由契约生成；Problem Details 覆盖；权限矩阵有自动化测试；重复 Idempotency-Key 不产生第二次副作用；SSE 断线续传不重复拼接；公开 API 不可绕过发布与 visibility 规则。
