# AI Hotspot 产品验收标准

> 文档状态：草案。本文件定义产品级结果，具体数值将在真实样本和本地硬件确认后校准。

## 1. 总体验收

MVP 验收需要同时满足：

- 在本地电脑上按照文档启动完整系统；
- 使用真实信源完成采集和内容处理；
- 用户端、研究端和管理端均可使用；
- 关键数据可追溯；
- 高风险操作有权限、确认和审计；
- 核心链路具备自动化测试；
- 不使用伪造引用或把固定 Mock 当成最终功能。
- 无真实模型 API Key 时可以使用 Mock Provider 启动和运行自动化测试。

## 2. 内容产品验收

- 精选页可以显示真实处理后的内容；
- 游客无需登录可访问精选、全部公开动态、日报、主题、公开详情和公开搜索；
- 未登录用户不能使用 RAG、收藏、订阅、Agent 和管理端；
- 热点按事件展示并显示独立信源；
- 分类、主题、来源、时间和语言筛选有效；
- 内容详情展示来源、摘要、标签、事件关系和原文入口；
- 事件详情展示主条目、关联内容、时间线和来源角色；
- 收藏在登录用户范围内持久保存；
- 日报可以生成、编辑、预览和发布；
- 受限内容按策略隐藏正文。
- 全部动态只出现 PUBLISHED + PUBLIC 且通过准入的内容；
- UNCONFIRMED 内容有明显标记且默认不进入精选；
- DEBUNKED 内容从默认结果移除；
- 纠错和下架反馈可以形成管理工单并完成下架、恢复和审计。

## 3. 采集与运营验收

- 管理员可新增信源主体和入口；
- 试抓取返回入口类型、样本和建议配置；
- 确认后才创建正式采集任务；
- RSS/Atom、网站/Sitemap、GitHub、Hugging Face、arXiv、OpenReview、Hacker News 和公开技术媒体至少各有真实成功样本；
- 原始响应保存在对象存储；
- 失败任务可重试并查看错误；
- 重复任务不会生成重复内容；
- 从内容可以追踪到原始响应和处理运行。
- 当前范围中不存在 X 或微信公众号自动采集模块、任务或验收依赖。

## 4. 内容质量验收

- 摘要结构符合 Schema；
- 摘要事实与原文抽检一致；
- 精确 URL 去重在固定样本中无重复；
- 近重复和事件关联使用人工标注样本评测；
- 一篇内容可以关联多个事件；
- 人工纠正可以保存理由和审计；
- 评分保存分项值、算法版本和解释。

## 5. 搜索与 RAG 验收

- 全文搜索和向量搜索均可独立工作；
- 混合检索支持时间、来源等级、主题、实体和语言过滤；
- 事件级折叠生效；
- 回答中的引用全部指向真实检索结果；
- 引用能定位到具体知识切片；
- 官方来源限制遵从率为 100%；
- 权限过滤发生在检索前，用户不能召回或引用无权访问的 PRIVATE_RAG 内容；
- 资料不足问题返回明确说明；
- 至少建立一套固定 RAG 评测集并输出指标。

## 6. Agent 验收

- Research Agent 可以完成一次带引用研究；
- Subscription Agent 可以解析并预览订阅；
- Source Operations Agent 可以试抓取但不能绕过正式确认；
- Crawler Operations Agent 可以读取失败并提出建议；
- 高风险工具进入等待审批状态；
- 拒绝后不得继续执行原写操作；
- 每次运行可查看计划、步骤、工具、费用、错误和结果。

## 7. 邮件验收

- 用户可以创建每日和每周订阅；
- 邮件可在 Mailpit 中完整预览；
- 可配置真实 SMTP；
- 同一订阅和时间窗口不会重复发送；
- 邮件包含站内链接和来源；
- 发送失败可以重试并查看历史。
- 每封邮件具有可用的一键退订和偏好入口；
- 退订后后续计划任务不得继续发送。

## 8. 安全与权限验收

- 未授权用户不能访问管理功能；
- 服务端独立校验权限，不依赖前端隐藏；
- 抓取禁止内网、localhost 和云元数据地址；
- 日志不输出密钥、Token、Cookie 和 Authorization；
- 内容下架后从公开页面、搜索、缓存和 RAG 中移除；
- Agent 提示注入测试不能获得越权工具能力。

## 9. 本地运行验收

- 提供一条主启动命令；
- 所有服务有健康检查；
- 提供初始化、种子数据和迁移命令；
- 支持停止后恢复，不丢失数据库和对象存储；
- 提供轻量和完整运行配置；
- Windows 标准运行方式为 Docker Desktop + WSL2 + Docker Compose；
- RabbitMQ 的失败重试、死信和人工重放可以验证；
- 数据库事务与消息发布通过 Transactional Outbox 保证；
- Consumer Inbox 能阻止重复 LLM、Embedding、报告或邮件副作用；
- 文档说明常见故障和清理方式。

## 10. 最终验收证据

验收时必须提供：

- 版本号和提交记录；
- 环境配置说明；
- 自动化测试报告；
- Connector 固定样本结果；
- 内容质量抽检结果；
- RAG 评测结果；
- Agent 权限测试；
- 本地运行截图或录屏；
- 已知限制和未完成项。
