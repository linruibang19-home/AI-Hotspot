## 2. 内容发现功能

### 2.1 精选

- 今日热点；
- 日期分组时间线；
- 分类 Tab；
- 搜索和筛选；
- 内容卡片；
- 收藏；
- 进入内容或事件详情；
- 查看推荐理由和其他信源。

### 2.2 全部动态

- 只展示通过准入规则、状态为 PUBLISHED 且 visibility 为 PUBLIC 的内容；
- 按时间、分类、主题、来源等级、语言、状态筛选；
- 按最新、评分和影响力排序；
- 标记已读、未读和收藏；
- 分页或游标加载。

原始池、候选池、重复内容、审核失败和非公开内容只能在授权管理页面查看。

### 2.3 热点事件

- 热点排名；
- 独立信源数量；
- 事件更新时间；
- 热度变化；
- 主条目；
- 关联内容和来源分布。

### 2.4 日报

- 当日概览；
- 重点事件；
- 分类摘要；
- 数据统计；
- 历史日报；
- 邮件订阅；
- 管理员编辑、预览和发布。

### 2.5 主题

- 公司与模型；
- 技术方向；
- 内容形态；
- 主题简介、趋势和统计；
- 近期事件和精选；
- 相关实体；
- 订阅和发起研究。

### 2.6 搜索

- 内容、事件、主题和实体统一搜索；
- 关键词高亮；
- 时间和来源过滤；
- 结果类型切换；
- 保存搜索或创建订阅；
- 从搜索结果发起研究。

## 3. 知识研究功能

### 3.1 RAG 问答

- 输入自然语言问题；
- 显式设置时间、主题、实体、来源等级和语言；
- 显示查询理解结果；
- 流式输出；
- 显示证据和引用；
- 资料不足提示；
- 继续追问。

### 3.2 研究模式

- 快速问答；
- 多实体对比；
- 事件时间线；
- 深度研究报告；
- Markdown 导出；
- 保存和重新运行。

### 3.3 研究任务详情

- 用户目标；
- 解析后的过滤条件；
- 检索过程；
- 证据列表；
- 中间结论；
- 最终报告；
- 引用；
- 模型、耗时和费用。

## 4. 订阅与邮件功能

- 自然语言解析；
- 结构化筛选表单；
- 时间窗口和时区；
- 最大条数；
- 来源等级；
- 邮件地址和投递频率；
- 创建前预览；
- 启用、暂停、修改和删除；
- 测试发送；
- 投递历史和错误详情。

## 5. Agent 功能

### 5.1 Research Agent

搜索、比较、构建时间线、组织证据并生成研究报告。

### 5.2 Subscription Agent

解析订阅需求、预览规则、创建或修改订阅。写操作需要确认。

### 5.3 Source Operations Agent

检测来源类型、试抓取、检查重复并推荐配置。正式创建和停用需要确认。

### 5.4 Crawler Operations Agent

分析失败、结构变化、积压和重试，提出解析规则建议。应用变更需要确认。

## 6. 运营管理功能

### 6.1 信源管理

- 主体与入口；
- 来源等级；
- Connector；
- 采集周期；
- 内容策略；
- 健康状态；
- 凭据状态；
- 启用和暂停；
- 批量导入。

只有 ADMIN 和 OPERATOR 可以新增或修改信源。

### 6.2 采集监控

- 任务状态；
- 结果数量；
- 延迟；
- HTTP 状态；
- 重试；
- 死信；
- 结构变化；
- Endpoint 健康；
- 从任务追踪到原始响应。
- 重试队列和死信队列；
- 失败任务人工重放。

### 6.3 内容审核

- 低置信度提取；
- 分类和实体冲突；
- 精选候选；
- 版权策略异常；
- 传闻和低相关内容；
- 摘要和推荐理由编辑。

### 6.4 事件审核

- 合并和拆分；
- 跨事件关联；
- 主条目选择；
- 来源关系；
- 置信度和理由；
- 人工纠正样本。

### 6.5 模型与 Prompt

- 任务模型路由；
- 主模型和回退模型；
- Prompt 版本；
- 灰度；
- 评测结果；
- Token、延迟和费用；
- 发布和回滚。

## 7. 跨功能能力

- 登录和权限；
- 审计；
- 通知；
- 全局错误处理；
- 主题模式；
- 响应式；
- 可访问性；
- 操作确认；
- 数据导出；
- Trace 追踪；
- 内容纠错和下架。
- 邀请码注册和公开注册开关；
- UNCONFIRMED 与 DEBUNKED 状态；
- 展示策略和索引策略；
- Transactional Outbox 与 Consumer Inbox 运行状态。
