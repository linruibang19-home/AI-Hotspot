# 可借鉴与不可照搬清单

> 文档状态：草案

## 1. 可以借鉴的产品方法

| 方向 | 可借鉴内容 | AI Hotspot 的处理方式 |
|---|---|---|
| 信息架构 | 精选、全部、日报、主题、收藏 | 保留核心路径，并增加事件、搜索、研究和订阅 |
| 首页 | 当前热点 + 时间线精选 | 以事件作为热点对象，以内容作为时间线条目 |
| 内容卡片 | 来源、评分、摘要、标签、推荐理由 | 增加来源等级、事实类型和关联事件 |
| 内容编辑 | 摘要与推荐理由分离 | 分别保存事实摘要和编辑价值判断 |
| 热点 | 展示多信源同时报道 | 统计独立信源并区分转载链 |
| 主题 | 长期主题入口 | 明确公司/模型、技术方向、内容形态三类主题 |
| 日报 | 对当天高价值内容进行精编 | 生成后允许审核、版本化、发布和邮件推送 |
| 视觉 | 高密度、低干扰、冷灰和青绿 | 建立独立品牌变量和组件细节 |
| 外部接入 | RSS、只读 API、Agent Skill | 作为后续能力，不与站内 Agent 概念混淆 |

## 2. 必须由 AI Hotspot 自主设计的部分

- 品牌名称、Logo 和视觉识别；
- 内容评分维度和权重；
- 精选准入和人工审核规则；
- 信源等级和权威分；
- Connector 体系；
- 事件聚类与跨事件关联；
- 数据库和服务架构；
- 受限正文的展示与索引策略；
- RAG 检索、引用和资料不足策略；
- Agent 工具、权限和审批；
- 邮件订阅和投递；
- 管理后台和审计；
- 测试、评测、监控和成本控制。

## 3. 不可照搬的内容

### 3.1 品牌与视觉资产

- AI HOT 名称和 Logo；
- 完全相同的品牌字体和图形；
- 逐像素复制页面；
- 复制其页面文案和推荐理由。

### 3.2 数据与内容

- 复制其资讯、摘要、标签或评分；
- 批量镜像其站内详情；
- 将其公开 API 当作 AI Hotspot 的核心数据源；
- 假设其公开内容已经授权二次发布。

### 3.3 不可见的实现

- 推测并复制其爬虫方案；
- 推测其数据库、模型、Prompt 或评分公式；
- 根据页面表现认定其事件聚类完全自动；
- 推断其公众号采集方式；
- 推断其内部审核和版权授权关系。

## 4. 设计边界

AI Hotspot 的目标不是“做一个换 Logo 的 AI HOT”，而是：

> 继承高质量 AI 资讯产品的交互经验，自主建立可运营、可追溯、可研究、可扩展的 AI 情报系统。

## 5. 后续原型检查项

新原型完成后，应逐项检查：

- 是否能看出受 AI HOT 启发，但不存在品牌混淆；
- 是否保持高信息密度而没有直接复制布局细节；
- 是否突出来源、事件和证据；
- 是否补充事件详情、搜索、研究、订阅和管理能力；
- 是否具备完整状态而非只展示理想数据；
- 是否使用 AI Hotspot 自己的数据结构和示例内容。
