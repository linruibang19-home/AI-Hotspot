# AI Hotspot 内容处理、评分与模型路由

> 文档状态：M0 冻结候选。

## 1. Provider 抽象

必须定义 `GenerationProvider`、`EmbeddingProvider`、`RerankProvider`，统一输入、超时、错误、用量和健康检查；配置包含 provider、baseUrl、model、credentialRef、timeout、retry、parameters，禁止硬编码地址、模型和密钥。

默认：DeepSeek OpenAI-compatible 生成；BAAI/bge-m3 Embedding；BAAI/bge-reranker-v2-m3 Rerank。三类都提供 Mock Provider；无 API Key 时系统可启动、跑通采集到展示、RAG 固定答案和自动化测试。本地不运行大型生成模型；Embedding/Rerank 可配置本地或远程。

## 2. 内容处理流水线

```text
原始条目 → URL/语言标准化 → 正文提取 → 内容策略判定 → 硬去重
→ 中文标题/摘要 → 分类/实体/标签 → 评分 → 近重复与事件候选
→ 发布准入 → 可索引内容切片 → Embedding
```

每步保存输入 Hash、实现/Prompt/模型版本、结构化结果、耗时、用量和错误。上一步策略禁止全文时，不得把正文传给后续模型。

生成输出通过 JSON Schema 校验：中文标题、摘要、分类、实体、标签、事实声明、推荐理由及置信度。失败先做一次结构化修复；仍失败进入人工/重试，不用不完整结果公开。

## 3. 评分

评分 0～100，默认准入 relevance≥70、quality≥60。最终分为可配置加权：来源权威、第一方、AI 相关度、质量、新颖、影响、信息密度、独立信源、时效减去重复、传闻、营销和策略惩罚。

硬规则优先于总分：DEBUNKED、策略禁止、提取失败、重复从条目不能靠高总分发布。`UNCONFIRMED` 强制降权且默认不能精选。普通用户只展示最终分和精选理由；维度、权重和解释只在管理端。

## 4. 模型路由与降级

- 路由按 taskType（translate/summarize/classify/extract/rag/agent）选择主模型、回退模型和预算。
- 429/5xx/超时按策略重试；Schema 错误不盲目换模型多次消耗。
- 生成服务不可用时：采集与原始池继续，公开发布暂停或仅允许不需 AI 且人工审核的内容。
- Embedding 不可用时：全文搜索继续，向量/RAG 显示降级；不得返回伪造引用。
- Mock 结果必须显著标识开发环境，禁止进入生产公开数据。

## 5. Prompt 生命周期

状态 `DRAFT → EVALUATED → ACTIVE → RETIRED`；每个 taskType 仅一个 Active。发布需记录评测集、指标、负责人和变更说明；回滚只切路由，不覆盖历史。模板不得拼接未经边界标记的网页指令；网页正文作为不可信数据封装。

## 6. 成本与隐私

按 modelRun 记录输入/输出 token、估算费用、缓存命中和用户/任务归属。日志不保存密钥和完整私有正文；敏感输入按策略脱敏。设置单任务、单用户和每日预算，超限返回可解释错误。
