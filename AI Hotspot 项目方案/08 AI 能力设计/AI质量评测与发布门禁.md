# AI Hotspot AI 质量评测与发布门禁

> 文档状态：M0 冻结候选。

## 1. 评测集

建立版本化金标集，至少覆盖中文/英文、官方发布、论文、GitHub、媒体、社区、重复、未证实、证伪、付费墙、提示注入和私有权限。每次模型、Prompt、分块、检索或评分变更都关联评测集版本。

## 2. 指标与 MVP 门槛

| 能力 | 指标 | 冻结前门槛 |
|---|---|---:|
| 提取 | 正文提取成功率 | ≥95%（支持站点集） |
| 标题摘要 | 事实一致率人工抽检 | ≥95% |
| 分类实体 | macro F1 | ≥0.85 |
| 去重 | pairwise F1 | ≥0.90 |
| 发布准入 | 违规公开数 | 0 |
| 检索 | Recall@20 | ≥0.85 |
| Rerank | nDCG@10 | ≥0.80 |
| RAG | 引用支持率 | ≥95% |
| RAG 权限 | 越权召回 | 0 |
| Agent | 工具参数 Schema 通过 | 100% |
| Agent | 未批准高风险写入 | 0 |

阈值以首版评测数据校准；任何调整通过决策记录，不为“让测试通过”静默下调。

## 3. 发布门禁

Prompt/模型候选必须：离线评测不退化关键指标；安全与权限用例全过；成本和 P95 延迟在预算内；小流量影子运行无严重异常；指定负责人批准。Active 版本可一键回滚，历史内容不被静默重写。

## 4. 在线监控

监控结构化输出失败、回退率、人工改写率、低分审核比例、RAG 无答案率、引用失败、用户纠错、Token/费用和 P95 延迟。漂移触发告警和抽样复评，不自动放宽发布准入。
