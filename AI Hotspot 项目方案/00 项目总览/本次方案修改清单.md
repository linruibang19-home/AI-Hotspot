## 2. 决策迁移

- Q-001 至 Q-020 已从《待确认问题》移除；
- 全部内容进入《已确认决策》；
- 《待确认问题》仅保留认证实现、Java 数据层、本地/远程 bge、首批信源、保留期限、自动发布、Beta 基础设施和公开 API 等后续详细决策；
- 新增模块化三端架构、RabbitMQ、Outbox、Inbox 和不采用基础设施的正式决策。

## 3. 产品与用户修改

- MVP 明确面向个人和邀请制小范围用户；
- 不开放公众自由注册；
- 增加管理员建号和邀请码；
- 游客可以浏览精选、全部公开动态、日报、主题、公开详情和搜索；
- RAG、收藏、订阅、Agent 和管理端需要登录；
- UI 以中文为主，保留英文原文和 i18n Key；
- 只有 ADMIN 和 OPERATOR 可以新增或修改信源。

## 4. 内容与版权修改

- “全部动态”重新定义为 PUBLISHED + PUBLIC 的准入内容池，不是原始全量池；
- 增加默认 relevance_score ≥ 70 和 quality_score ≥ 60，阈值配置化；
- 增加 UNCONFIRMED 标记、降权和默认不精选；
- 增加 DEBUNKED 状态和默认结果移除；
- 普通用户只见最终分，评分分项仅管理端；
- display_policy 和 index_policy 分离；
- 付费墙、登录和明确受限内容不保存全文、不切片、不向量化；
- 只有管理员确认有权使用的上传材料可进入 PRIVATE_RAG；
- 增加纠错、下架、恢复、管理工单和审计。

## 5. 信源范围修改

从当前项目范围删除：

- X API、X 登录态、非公开接口和自动采集；
- 微信公众号扫码授权、自动订阅和登录态采集；
- WeChat Collector、WeRSS；
- X 或公众号批量发现；
- 人工复制相关 URL 作为核心能力。

正式信源范围调整为 RSS/Atom、官方网站、Sitemap、GitHub、Hugging Face、arXiv、OpenReview、Hacker News、公开 AI 技术媒体和开发者社区。

## 6. AI 与检索修改

- GenerationProvider 默认 DeepSeek OpenAI-compatible API；
- EmbeddingProvider 默认 BAAI/bge-m3；
- RerankProvider 默认 BAAI/bge-reranker-v2-m3；
- 增加三类 Mock Provider；
- 模型、地址、密钥、超时、重试和任务映射配置化；
- 本地不运行大型生成模型；
- MVP 不支持用户自带 API Key；
- 权限过滤移到检索之前；
- RAG 和 Agent 不得引用用户无权访问的 PRIVATE_RAG。

## 7. 邮件修改

- 开发使用 Mailpit，生产通过 MailProvider 使用 SMTP；
- MVP 支持每日和每周简报；
- 默认 Asia/Shanghai，每日 09:00、每周一 09:00；
- 即时推送移出 MVP；
- 增加一键退订和偏好入口；
- 记录成功、失败、重试和退订状态；
- 打开率和点击率不作为 MVP 强制指标。

## 8. 架构与异步修改

- RabbitMQ 加入正式技术架构；
- Redis Streams 从核心异步方案中移除；
- Redis 仅负责缓存、锁、限流和短状态；
- 增加 `aihot.events` Topic Exchange；
- 增加 7 个主 Worker 队列；
- 增加统一事件 Envelope；
- 增加 Persistent Message、Publisher Confirm、Manual ACK 和 Prefetch；
- 增加 1/5/30 分钟重试；
- 增加 DLX/DLQ；
- 增加 Transactional Outbox；
- 增加 Consumer Inbox；
- 增加管理端失败任务查看和人工重放；
- 明确 MVP 不使用 Kafka。

## 9. 数据模型修改

- 新增邀请制账号和邀请码；
- 新增 FetchArtifact 与 RawEntry 分层；
- SourceEndpoint 枚举删除 X/微信公众号；
- 内容新增 publication_status、visibility、display_policy、index_policy 和 fact_status；
- 内容与事件改为显式多对多；
- 新增 KnowledgeDataset 区分 PUBLIC/PRIVATE；
- 新增订阅运行、邮件投递和退订状态；
- 新增反馈工单和管理动作；
- 新增 Outbox、Inbox 和死信记录；
- 补充模型、Prompt、Agent、审批和审计对象。

## 10. 部署修改

- Windows 统一 Docker Desktop + WSL2；
- Docker Compose 是唯一标准运行方式；
- PowerShell 只提供 Compose 辅助命令；
- Compose 新增 RabbitMQ 和多个 Worker 进程；
- Beta 初始部署为单台 Linux + Docker Compose + Nginx + HTTPS；
- 不使用 Kubernetes、Kafka、Elasticsearch/OpenSearch、多节点数据库和多区域部署。

## 11. 里程碑与验收修改

- 路线图更新为 M0～M10；
- RabbitMQ、Outbox、Inbox、权限和审计在基础阶段进入；
- 新增 OpenReview Connector；
- 删除所有 X/微信公众号采集里程碑；
- 增加公开准入、UNCONFIRMED/DEBUNKED、PRIVATE_RAG 权限验收；
- 增加每日/每周邮件、退订、重试和死信验收；
- 增加 RabbitMQ 故障、重复投递和人工重放验收；
- 增加邀请制 Beta 准备阶段。
