## 3. 本轮关键整改

- 现有采集记录全部保留来源审计，但 Mock 生成的中文标题、摘要、推荐理由和评分被清空；公开内容数为 0，直到真实模型重新处理并通过阈值。采集记录数会随 Worker 运行增长，因此不在进度文档固化瞬时总数。
- V016/V018 数据库触发器和 Worker 真实 Provider 门禁共同防止以后再次写入可展示的 Mock 分析或重新关联到主题事件。
- 公开接口、精选、报告、收藏和主题查询统一要求成功的非 `mock/test/fixture` Provider。
- 主题详情按发布日期分组、按发布时间倒序显示；无真实审核内容时展示诚实空状态。
- 内容评分采用《08 AI 能力设计》维度：AI 相关性、完整性、清晰度、来源证据、新颖性、影响、信息密度、营销惩罚、传闻惩罚；推荐理由必须引用文章中的具体信息，禁止“来自公开信源/通过质量分析”套话。
- RAG 配置、评测、指标、索引重建、发布就绪、邮件投递和 Agent 审批均提供管理页面。
- 管理端模型页提供“重新分析内容”批处理入口；只应在真实 Generation Provider 启用并通过烟测后执行，批次最多 500 条，重新生成非 Mock 分析并重新走发布阈值。
- 新增 `scripts/complete-m7-m10.ps1`：只有三个真实 Provider 均通过烟测后，才会激活治理配置、分批重处理历史内容、等待 Worker、回填向量、执行带引用研究、运行黄金集并要求 M10 门禁 `PASS`。
- 浏览器自动化固定使用项目根目录 `agent-browser.json` 的无头模式；测试结束必须关闭 Session，避免 Chrome for Testing 小窗闪烁。

## 4. 数据与运行状态

- Flyway：V001～V020，只前进不修改历史迁移；V019 更新远程模型默认值，V020 建立 10 条中文 RAG 黄金评测用例和明确阈值。
- 业务表：54 张；`automation` 9、`content` 13、`governance` 4、`iam` 7、`knowledge` 10、`messaging` 3、`research` 3、`source` 5。
- 正式信源目录：82 个定义/Endpoint；X 仅保留禁用的预留契约，不采集。
- 标准运行方式：Docker Compose；本地端口见《本地中间件与数据库连接指南》。
- 当前 Provider：Mock，仅供工程自测；发布门禁使其无法产生公开内容、RAG 文档或正式推荐理由。
- 历史死信不会删除：端点后续成功或已经归档时标记为 `IGNORED`；尚未恢复的失败继续保持 `PENDING` 并阻塞就绪检查。当前 `PENDING=0`。
- 2026-07-20 现场检查：全部 Compose 容器在线；滚动近 24 小时窗口新增 198 条真实原始记录，抓取任务成功 2067 次。当前公开内容为 0 的直接原因是三个 AI Provider 仍为 Mock，全部 1949 条规范化内容均被真实 Provider 门禁隔离，并非采集停止。滚动窗口数字会随检查时刻变化。
- 正式信源共 82 个，其中 79 个处于 `ACTIVE + HEALTHY`；3 个暂停/待专用适配（Hugging Face Daily Papers、OpenReview Public Notes、xAI Company News）。RabbitMQ 物理 DLQ 仍保留 92 条历史消息供审计，数据库待处理死信为 0。
- 2026-07-20 本地备份验证：PostgreSQL 自定义格式转储 6,273,788 字节；MinIO TAR 归档 811,812,352 字节。`scripts/verify-backup-restore.ps1` 已在临时数据库和临时 MinIO 卷完成隔离恢复，验证 54 张业务表、1949 条内容及 MinIO 健康，不覆盖当前运行数据；异机恢复仍属于 Beta 前验收项。

## 5. 验收门禁

必须同时满足后才能称为 Beta 就绪：

1. `GENERATION_PROVIDER`、`EMBEDDING_PROVIDER`、`RERANK_PROVIDER` 都连接真实服务，且管理端 Provider 配置为 `ACTIVE`。
2. 真实模型重新处理内容，公开池中不存在空 Provider 或 Mock Provider。
3. RAG 黄金集通过引用支持度、ACL 零泄漏、召回和延迟阈值。
4. 邮件真实 SMTP、退订和失败重试通过。
5. PostgreSQL 与 MinIO 在独立目录/主机完成一次可验证恢复。
6. Linux + Nginx + HTTPS 连续运行验收通过。

## 6. 剩余任务

当前剩余任务不再是编写 M7～M10 功能，而是外部配置和上线级放行：把新生成且未公开泄露的模型密钥写入本机 `.env`，执行 `scripts/complete-m7-m10.ps1`；随后配置生产 SMTP，完成 Linux/HTTPS/异机恢复、域名备案和内容合规。截图中出现过的密钥应先轮换，禁止写入 Git、日志或项目文档。Git 仍只在本地分支提交；未提供远程仓库前不擅自 push。
