# AI Hotspot 项目进度与剩余任务

> 更新时间：2026-07-25；这是全项目当前状态的唯一事实来源。瞬时数据以本轮 PostgreSQL、Docker Compose、自动化测试和发布门禁为准。

## 1. 总体结论

M0～M10 已完成本地产品闭环，当前阶段是“稳定性、信源质量、RAG 质量与公开 Beta 准备”，不是重新搭建框架。产品已有公开资讯、主题时间线、日报/周报/月报、邮箱注册登录、收藏订阅、RAG 研究、受控 Agent 和管理治理。DeepSeek Generation、SiliconFlow `BAAI/bge-m3` Embedding 与 `BAAI/bge-reranker-v2-m3` Rerank 已接入真实服务；公开产品与 RAG 中 Mock 内容为 0。

本地闭环不等同于互联网公开 Beta。生产 SMTP、Linux/Nginx/HTTPS、异机恢复、域名备案和内容合规仍需目标环境验收。

## 2. 当前实际架构

- 代码应用：`apps/web`、`services/core`、`services/ai`，共 3 个；
- Compose 服务：Web、Core API、AI API、Worker、PostgreSQL+pgvector、Redis、RabbitMQ、MinIO、Mailpit、Nginx，共 10 个；
- PostgreSQL：单实例、8 个业务 Schema、57 张业务表（另有 `public.flyway_schema_history`）；
- Worker：一个 Python Worker 消费采集、内容分析、索引等多类队列；
- 运行标准：Docker Compose；PowerShell 仅包装启动、停止、测试和运维；
- 当前不需要 LangGraph。只有当 Agent 出现持久化图状态、复杂循环/并行分支且现有状态机无法维护时才重新评估。

## 6. 当前产品边界

- 游客可浏览公开精选、全部动态、报告、主题、内容详情和公开搜索；
- 普通用户开放邮箱验证码注册与登录，收藏、订阅、RAG 与 Agent 登录后使用；
- 管理端只允许 ADMIN/OPERATOR；引导管理员账号由本机 `.env` 创建；
- X 与微信公众号不采集，X 只保留禁用的扩展契约；
- 不支持用户自带模型 Key；密钥仅存本机 `.env`；
- 不使用 Kubernetes、Kafka 或 Elasticsearch。
