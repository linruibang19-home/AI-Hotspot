# AI Hotspot 方案阅读说明

> 当前状态：现行说明；更新时间 2026-07-22。

## 1. 阅读入口

请从方案根目录的 [项目方案总入口](../README.md) 开始。总入口已经把几十份材料压缩为 8 份必读文档，并规定当前状态、架构和任务分别只有一个权威来源。

## 2. 文档状态

| 状态 | 使用方式 |
|---|---|
| 现行 | 当前实现和后续开发的正式依据 |
| 支撑 | 解释某个产品、页面、领域或运维细节，不单独声明全局进度 |
| 历史证据 | 评审、任务拆分、基线和验收记录；用于追溯，不作为当前事实 |
| 已废弃 | 已被明确替代，只保留替代原因 |

标题含“评审”“任务拆分”“验收记录”“基线记录”的文档统一按历史证据阅读，即使正文保留了当时的“已完成”表述。

## 3. 当前开发阶段

M0～M10 的本地产品闭环已经实现，当前不是 M1 或 M6 开发阶段。现阶段是：

- 本地稳定性与数据质量修复；
- 信源质量、时间准确性和多样性持续优化；
- RAG 质量、评测、冲突证据和性能优化；
- 公开 Beta 前的 SMTP、Linux、HTTPS、异机恢复与合规准备。

实时状态和剩余工作只看 [项目进度与剩余任务](./项目进度与剩余任务.md) 与 [后续任务清单](../11%20开发与交付计划/后续任务清单.md)。

## 4. 变更规则

1. 产品规则变化先更新《已确认决策》，再修改代码。
2. 架构变化更新《系统总体架构》，重大取舍新增 ADR。
3. 数据库变化新增 Flyway 迁移，并更新字段中文说明。
4. 每次阶段收口都更新唯一进度文档和唯一任务清单。
5. 不删除有审计价值的历史记录，但不在历史文档继续追加当前状态。
6. 所有代码、迁移、测试和文档变更必须进入 Git；未经授权不 push 远程仓库。
