# AI Hotspot 领域服务与业务命令

> 文档状态：M0 冻结候选；用于 Core API 的应用服务拆分。

## 1. 聚合边界

| 聚合 | 聚合根 | 主要命令 |
|---|---|---|
| 身份 | UserAccount | Invite、Activate、AssignRole、Suspend |
| 信源 | SourceEntity | AddEndpoint、Probe、Activate、Pause、UpdatePolicy |
| 采集 | FetchJob | Schedule、Start、Complete、Fail、Retry |
| 内容 | ContentItem | Normalize、Score、Publish、Unpublish、Restore、MarkFact |
| 事件 | EventCluster | Attach、Detach、SetPrimary、Merge、Split、Relate |
| 报告 | Report | Generate、Revise、Publish、Withdraw |
| 订阅 | Subscription | Create、Activate、Pause、Unsubscribe、Run |
| 研究 | Conversation/ResearchJob | Ask、Retrieve、Answer、Cancel |
| Agent | AgentRun | Plan、ExecuteStep、RequestApproval、Approve、Cancel |
| 治理 | FeedbackTicket | Triage、Resolve、Takedown、Restore |

## 2. 领域服务

- `PublicationEligibilityService`：依据配置快照、质量、事实、重复和策略判断可发布性。
- `ContentPolicyService`：分别给出展示、索引、正文保留和引用策略。
- `DuplicateDecisionService`：判断主条目并生成重复关系，不直接删除从条目。
- `EventAssociationService`：计算事件候选、跨事件关系和置信度，低置信进入审核。
- `RetrievalAuthorizationService`：把用户、数据集和对象 ACL 编译为检索前过滤条件。
- `SubscriptionSchedulerService`：按时区生成唯一 Run，处理错过执行和退订竞争。
- `ApprovalPolicyService`：确定 Agent 工具风险级别及审批要求。

## 3. 命令返回约定

命令成功返回聚合 ID、版本、状态、审计 ID 和可选 Job ID。命令接受 `Idempotency-Key` 与 `expectedVersion`；重复键返回原结果，版本冲突返回 409。验证错误不发布事件；成功事务同时写入领域变更和 Outbox。

## 4. 禁止的跨边界写入

- Python Worker 不直接决定公开发布，仅写处理结果并发出完成事件，由 Core 执行发布规则。
- Web 前端不直接访问数据库、MinIO 或 RabbitMQ。
- 通知 Worker 不修改订阅偏好，只读取发送前快照并回写投递结果。
- Agent 工具只调用受审计业务 API，不绕过应用服务写表。
- 管理端批量操作仍逐对象执行权限、版本和业务规则。

## 5. 关键领域事件

`EndpointActivated`、`CrawlRequested`、`ContentProcessed`、`ContentPublished`、`ContentUnpublished`、`FactStatusChanged`、`EventMembershipChanged`、`ReportPublished`、`SubscriptionRunCreated`、`EmailRequested`、`ApprovalRequested`、`AgentRunCompleted`、`FeedbackResolved`。

事件名称使用过去式事实；事件 Schema 版本只增不改。敏感内容使用对象引用，不写入 payload。
