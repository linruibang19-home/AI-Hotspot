# 认证、目录与前端性能验收记录

> 验收日期：2026-07-18  
> 适用阶段：M2 身份权限能力复核、M5 后正式 Web 前端质量整改

## 一、认证与权限结论

- 游客继续允许访问精选、全部公开动态、报告、主题、公开内容详情与公开搜索；
- 收藏、订阅与邮件、知识库问答和 Agent 工作台必须登录；
- 信源、采集、内容审核、模型与用户管理必须登录，并继续由服务端角色权限做最终判定；
- 智能工作区增加页面级会话保护，直接输入 `/subscriptions`、`/research` 或 `/agent` 不再显示受限工作区；
- 3000 端口增加同源 Core API 代理，CSRF、Session Cookie、登录、`/me` 与退出链路均可在直连 Web 时工作；
- 公众自由注册保持关闭，当前支持管理员创建账号和邀请链接注册。

已完成的 MVP 账号入口包括登录、退出、会话恢复、管理员创建账号、创建邀请码、邀请码注册、角色隔离、登录和邀请码限流、BCrypt 密码哈希、审计记录。自助找回密码、邮箱验证、用户自行修改密码和完整账号生命周期管理不在当前已完成范围，进入后续增强清单。

## 二、目录整理

- 根目录保留正式原型、工程目录、Compose、环境模板、包管理和仓库说明；
- 原 `AI_PULSE_DEVELOPMENT_SPEC.md` 与 `AI_PULSE_PROTOTYPE.html` 已迁移至 `archive/早期 AI Pulse 方案/`；
- 增加根目录 `项目目录说明.md`，记录目录职责、生成目录和归档边界；
- 清理 `.pytest_cache`、`.ruff_cache`、`.next`、`target` 和 `__pycache__` 等可再生缓存；
- 保留 `node_modules` 与 Python `.venv`，避免本地启动时重复安装大体积依赖；
- `.env`、运行数据和当前正式原型未移动、未删除。

## 三、性能整改

- 精选首屏从一次返回 50 条改为 12 条，并使用真实游标按 20 条继续加载；
- 全部动态首屏改为 20 条；
- 列表摘要限定展示长度，内容详情仍保留完整正文；
- 报告每个栏目首屏最多展示 6 条并截断超长摘要，避免周报/月报 DOM 过大导致标签切换延迟；
- 加载更多内容使用 `Set` 去重，避免随已加载数量增长的重复线性扫描；
- 390px 移动端修复 `100vw` 包含滚动条导致的横向溢出。

实测公开精选 API 负载从 `limit=50` 的 190886 字节降为 `limit=12` 的 13719 字节，首屏接口负载下降 92.8%。稳定后的精选页为 12 张卡片、约 429 个 DOM 节点，无横向溢出；390px 移动端同样无横向溢出。
