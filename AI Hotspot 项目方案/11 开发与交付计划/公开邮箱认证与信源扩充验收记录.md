## 2. 信源调整

修复并启用：Google AI、Google Cloud AI & ML、Meta Engineering、Mistral AI、腾讯混元、火山引擎、蚂蚁集团。部分中文官网列表依赖客户端渲染或页面结构不稳定，通用静态 Website Connector 无法持续得到有效条目；腾讯混元、火山引擎与蚂蚁集团最终分别切换到同主体的 `Tencent-Hunyuan/HunyuanVideo` 官方 Commits API、`volcengine/verl` 官方 Releases API 与 `inclusionAI/AWorld` 官方 Commits API，并以真实采集成功作为启用条件。

根据 Awesome RSSHub Routes 采纳 14 条与 AI Hotspot 高相关的官方或高质量直连 Feed：Hugging Face Blog、Google Research、GitHub Copilot Changelog、OpenAI Codex Releases、Claude Code Releases、Gemini CLI Releases、MCP Specification、MCP Servers、Hacker News LLM、V2EX 技术、少数派、阮一峰科技周刊、Cloudflare Engineering、Vercel。

仍明确暂停的 3 条：

1. Hugging Face Daily Papers 专用 API：结构不稳定，已由官方 Blog RSS 提供稳定替代；
2. OpenReview Public Notes：当前公开 API 对采集请求返回 403，保留专用适配器等待上游策略调整；
3. xAI Company News：官网对采集请求返回 403；它是 xAI 官网公司动态，不代表启用 X 平台采集。

公共 `rsshub.app` 路由在本地核验时返回 403，因此没有把公共实例设置为生产依赖。清单中的官方直连 Feed 已直接采用；未来如需动态 RSSHub 路由，应自建实例、增加健康检查和资源预算后再启用。

## 4. 后续风险

- 生产 SMTP、发信域名 SPF/DKIM/DMARC、验证码滥用监控仍属于 M10 上线准备；
- 普通用户账号停用、会话管理、管理员 MFA 和密码轮换 UI 仍需继续完善；
- 新增 Feed 要经过一段连续运行观察，不能仅凭单次 HTTP 200 判定长期健康；
- OpenReview、xAI 和未来 RSSHub 动态路由不得绕过上游访问策略。
