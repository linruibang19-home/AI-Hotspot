报告集成测试曾发现 MyBatis 直接映射 PostgreSQL `RETURNING UUID` 会触发 Java 模块反射异常。现改为返回文本并显式转换 UUID，真实 Compose 环境复测通过。

## 6. 已知限制

1. M5 首版事件聚类尚有大量单信源事件；M7 可用 Embedding 增强聚类和近重复，M9 再提供更完整的人工合并/拆分工具。
2. 无 DeepSeek Key 时使用 Mock Provider，部分历史摘要仍带 Mock 提示；真实中文生成质量需配置 Provider 后重新回填评测。
3. M6 搜索是 FTS 与中文包含匹配，不包含向量召回和 Rerank；后者属于 M7。
4. M6 只实现产品内报告编辑发布；订阅调度、邮件模板、退订和投递重试属于 M8。
5. X 仍只保留不可启用的 RESERVED 接口契约，未实现采集。
