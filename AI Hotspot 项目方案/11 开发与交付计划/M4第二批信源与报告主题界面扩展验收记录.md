## 3. 数据真实性边界

- 报告数量、独立信源数、官方信源数、精选数和正文均来自公开准入数据；
- 当前报告是规则化实时聚合，不冒充人工编辑成稿；正式编辑、修订、发布版本属于 M6；
- 生成模型未配置密钥时仍使用 Mock Provider，因此旧内容中可见 Mock 摘要；M5 负责真实 Provider、生成质量和评分治理；
- Website Connector 只适合服务端输出可识别链接的页面，动态页面必须暂停或开发专用适配器；
- 本次清理了 GitHub 关键词短串误匹配造成的导航内容，并增加回归测试。

## 4. 已解决问题

1. `AI` 子串误命中 `Maintainers`：短 ASCII 关键词改为词边界匹配；
2. GitHub RSS 含 DTD 被安全解析器拒绝：切换到官方 AI 专题网页并限定文章 URL；
3. 容器 UTC 导致归档日期减一天：前端直接解析 ISO 日期分量；
4. 移动端 Grid 子项最小宽度撑破视口：显式限制主内容宽度并允许报告轨道收缩；
5. 内置目录只插入不更新：改为生产目录幂等同步 URL、Connector、配置和状态；
6. Smoke 硬编码 19 个信源：改为从目录文件读取预期数量，并新增三类报告与主题页检查。
