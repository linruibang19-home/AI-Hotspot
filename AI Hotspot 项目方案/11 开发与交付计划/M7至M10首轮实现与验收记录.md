# M7 至 M10 本地交付与验收记录

> 日期：2026-07-19；2026-07-20 补充真实 Provider 终验。这里的“完成”指功能代码、迁移和本地验证完成；生产 SMTP、Linux/HTTPS 等上线条件仍阻止提前宣称公开 Beta 就绪。

## 0. 2026-07-20 RAG v2 与信源质量复核

- 公共流改用来源发布时间优先的 `effective_published_at`，防止历史内容因新入库被伪装成最新；V023 回填可验证的英文标题/链接日期。现场公开内容 1196 条、未来时间 0、缺来源时间 143 条，缺失值被监控而非静默隐藏。
- 精选首屏按信源限额，第三方最多 2 条、官方/一手最多 4 条；最终现场 50 条覆盖 19 个独立信源且 IT之家仅 2 条，不再占满时间线。
- V021 将信源、事件、权威分、质量分、有效发布时间冗余到 Chunk 并建立部分/复合索引；V022 使索引重建不破坏历史 Citation 审计；V023 修复来源日期回填与时间过滤污染。
- 索引改用可授权的原始正文而非模型摘要，现场复核为 1196 个 INDEXED 文档、2684 个 Chunk、2684 个 bge-m3 向量、69 个独立信源。
- 真实 Agent 产品问题回归：DeepSeek OpenAI-compatible 生成成功，10 条引用、6 个独立信源、7 条官方/一手证据、引用覆盖率 87.5%；官方限定回归达到 10 条引用、8 个独立信源和 100% 引用覆盖率，且不再召回被错误标为近期的 2025 年内容。管理端新增查询质量与索引完整度指标，黄金集门禁增加真实查询引用覆盖和来源多样性。

## 1. 真实数据与 AI 发布门禁

- 对数据库全部内容扫描后，历史 Mock Provider 生成的标题、摘要、推荐理由和评分已清空，相关内容降为 `REJECTED + PRIVATE`。
- Worker 遇到 Mock/Test/Fixture Provider 时不再执行或持久化内容分析，只留 `developmentOnly` 审计记录。
- V016 触发器提供第二道数据库门禁；V018 进一步阻止 Mock 内容重新关联到主题事件，防止其他写入路径绕过 Worker。
- 公开查询、报告、收藏、主题和知识索引都要求非 Mock Provider；没有真实模型时产品显示空状态。
- 评分 Prompt 按《08 AI 能力设计》输出具体维度、事实状态、置信度、中文标题/摘要和基于正文事实的推荐理由；禁止套话。

## 2. M7：权限前置 RAG

- 数据集 ACL 在检索 SQL 中先过滤，再执行 FTS、可选 bge-m3 向量召回和可选 bge-reranker-v2-m3 重排。
- 回答只使用前八条有权证据并生成逐条 Citation；无证据返回 `NO_EVIDENCE`。
- Generation 不可用时只做明确标注的证据摘录，不伪装为模型总结。
- 管理端支持 Provider 配置引用、运行时烟测、索引重建、24 小时指标、评测运行和历史查看。
- V020 提供 10 条中文黄金用例；评测实际计算 Recall@20、nDCG@10、引用支持度和 ACL 泄漏，不能再用空用例或历史成功记录通过门禁。
- DeepSeek Generation、SiliconFlow bge-m3 Embedding 与 bge-reranker-v2-m3 Rerank 已通过烟测；公开文档和向量已完成历史回填。

## 3. M8：订阅与邮件

- 支持每日和每周一、默认 09:00、Asia/Shanghai、最大条数、暂停/启用和即时测试发送。
- 邮件仅选取通过真实模型门禁的公开内容，包含 HMAC 一键退订和偏好入口。
- 没有合格内容时运行标记为 `SKIPPED`，不发送标题空白的简报；前端显示明确原因。
- Mailpit 作为本地 Provider；投递状态、错误、重试和退订均持久化。

## 4. M9：Agent

- 研究、订阅、信源运营、采集运维四类 Agent 定义持久化。
- 每次运行保存目标、权限快照、Trace、步骤、工具参数指纹、结果和错误。
- L2/L3 操作进入有时效的审批队列；拒绝、批准、过期均可审计。

## 5. M10：验收与运维

- 就绪检查覆盖 Mock 公开泄漏、三类运行时真实 Provider、五项治理配置、真实公开内容、索引文档、非空向量、最新 RAG 评测、失败信源、死信、ACL、待审批和失败投递。
- V017 将“端点后续已经成功”或“端点已经归档”的历史死信标记为 `IGNORED` 并保留审计；未恢复死信仍阻塞就绪。
- 实现验证码/指标/审批/工具参数保留任务和关键部分索引。
- 提供 PostgreSQL + MinIO 备份、显式确认恢复和 Compose 验证脚本。
