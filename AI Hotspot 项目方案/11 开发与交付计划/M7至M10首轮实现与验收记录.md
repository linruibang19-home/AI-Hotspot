# M7 至 M10 首轮实现与验收记录

> 日期：2026-07-19。这里的“完成”指功能代码、迁移和本地验证完成；真实模型、生产 SMTP、Linux/HTTPS 等外部条件仍由发布就绪门禁阻止提前宣称 Beta 就绪。

## 1. 真实数据与 AI 发布门禁

- 对数据库全部内容扫描后，历史 Mock Provider 生成的标题、摘要、推荐理由和评分已清空，相关内容降为 `REJECTED + PRIVATE`。
- Worker 遇到 Mock/Test/Fixture Provider 时不再执行或持久化内容分析，只留 `developmentOnly` 审计记录。
- V016 触发器提供第二道数据库门禁；V018 进一步阻止 Mock 内容重新关联到主题事件，防止其他写入路径绕过 Worker。
- 公开查询、报告、收藏、主题和知识索引都要求非 Mock Provider；没有真实模型时产品显示空状态。
- 评分 Prompt 按《08 AI 能力设计》输出具体维度、事实状态、置信度、中文标题/摘要和基于正文事实的推荐理由；禁止套话。

## 2. M7：权限前置 RAG

- 数据集 ACL 在检索 SQL 中先过滤，再执行 FTS、可选 bge-m3 向量召回和可选 bge-reranker-v2-m3 重排。
- 回答只使用前八条有权证据并生成逐条 Citation；无证据返回 `NO_EVIDENCE`。
- Generation 不可用时只做明确标注的证据摘录，不伪装为模型总结。
- 管理端支持 Provider 配置引用、索引重建、24 小时指标、评测运行和历史查看。
- 当前真实模型未配置，因此文档/向量为 0 是正确状态。

## 3. M8：订阅与邮件

- 支持每日和每周一、默认 09:00、Asia/Shanghai、最大条数、暂停/启用和即时测试发送。
- 邮件仅选取通过真实模型门禁的公开内容，包含 HMAC 一键退订和偏好入口。
- 没有合格内容时运行标记为 `SKIPPED`，不发送标题空白的简报；前端显示明确原因。
- Mailpit 作为本地 Provider；投递状态、错误、重试和退订均持久化。

## 4. M9：Agent

- 研究、订阅、信源运营、采集运维四类 Agent 定义持久化。
- 每次运行保存目标、权限快照、Trace、步骤、工具参数指纹、结果和错误。
- L2/L3 操作进入有时效的审批队列；拒绝、批准、过期均可审计。

## 5. M10：验收与运维

- 就绪检查覆盖 Mock 公开泄漏、真实 Generation、失败信源、死信、ACL、待审批和失败投递。
- V017 将“端点后续已经成功”或“端点已经归档”的历史死信标记为 `IGNORED` 并保留审计；未恢复死信仍阻塞就绪。
- 实现验证码/指标/审批/工具参数保留任务和关键部分索引。
- 提供 PostgreSQL + MinIO 备份、显式确认恢复和 Compose 验证脚本。
- V019 刷新远程 Provider 默认配置；管理端新增历史内容“重新分析”批处理入口，真实 Provider 未启用时不得触发。
