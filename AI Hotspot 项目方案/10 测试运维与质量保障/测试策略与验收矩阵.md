# AI Hotspot 测试策略与验收矩阵

> 文档状态：M0 冻结候选。

## 1. 测试层级

- 单元：领域状态机、评分硬规则、时区、权限条件、Connector 解析、Prompt 输出校验。
- 集成：Postgres/pgvector、RabbitMQ、Redis、MinIO、Mailpit、Provider Mock；使用 Docker Compose 真依赖。
- 契约：OpenAPI、消息 JSON Schema、Provider Adapter，生产者/消费者版本兼容。
- E2E：Playwright 覆盖游客、USER、OPERATOR、ADMIN 关键链路。
- AI 评测：固定金标集、权限/引用/注入与成本门禁。
- 非功能：性能、故障恢复、安全、备份恢复、无障碍与响应式。

## 2. 关键 E2E

1. 游客浏览精选 → 筛选全部动态 → 内容详情 → 事件详情 → 报告/主题/搜索。
2. 邀请注册 → 登录 → 收藏 → 创建每日订阅 → Mailpit 收信 → 退订后不再发送。
3. USER 提问 → 权限过滤 → 混合检索 → 流式答案 → 引用可定位。
4. OPERATOR 新增 RSS → 试抓取 → 激活 → 内容处理 → 审核 → 公开展示。
5. UNCONFIRMED 标记、默认不精选；改为 DEBUNKED 后公开/缓存/索引移除。
6. Agent 读取自动执行；高风险工具等待审批；参数变化使审批失效。
7. RabbitMQ 不可用时 Outbox 保留；恢复后发布；重复投递不重复邮件/Embedding。
8. 反馈工单 → 下架 → 410 → 恢复 → 审计可追溯。

## 3. 环境

`test` 使用 Mock Provider、固定时钟和确定性种子；`staging` 与生产拓扑一致但使用隔离账号；生产不运行破坏性测试。测试数据不得使用未经授权真实私有内容。

## 4. 质量门禁

合并前：格式/lint、类型、单元、契约、迁移校验、密钥扫描。主分支：集成、E2E、镜像漏洞扫描。Beta 前：AI 门槛、安全、性能、备份恢复、无障碍、响应式、运营 Runbook 全部通过。

## 5. 性能预算（MVP 基准）

在目标单机、正常缓存和 50 并发浏览下：公开列表 API P95 <500ms；内容详情 <700ms；全文搜索 <1s；混合召回（不含生成）<2s；首个 RAG 流式 token <5s；管理列表 <1s。后台任务不阻塞 Web；队列积压恢复能力需通过压测校准。

## 6. Definition of Done

需求与追踪 ID 关联；代码评审；测试通过；OpenAPI/迁移/运维文档更新；权限和错误状态覆盖；日志指标齐全；无新增高危漏洞；验收截图或记录可复现；Git 工作区干净且提交可回滚。
