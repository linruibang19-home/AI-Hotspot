## 3. 实测发现与修复

### 3.1 高权限页面前端门禁不一致

模型治理、报告编辑、发布就绪和运营审批页面此前会在未登录时渲染操作按钮并发起管理 API 请求。后端权限仍能阻止操作，但前端暴露了不应出现的控制面，并产生无意义的 401 请求。

修复后四页统一执行：

1. 会话检查期间只显示会话检查状态；
2. 未登录只显示登录入口；
3. 已登录但无权限只显示明确的权限说明；
4. 只有权限通过后才加载管理 API、数据和操作控件。

未登录无头复核中，四页主标题均为“需要登录”，模型烟测、生成草稿、重新检查、审批等高权限控件数量均为 0。管理员登录后四页恢复真实数据和操作界面。

### 3.2 内容详情重复一级标题

内容详情此前同时存在“内容详情”和文章标题两个 `h1`。现将页头改为语义中性的详情工具栏，文章标题成为页面唯一一级标题，返回入口和来源追踪说明保持不变。

### 3.3 移动端可读性和触控目标

- 收藏按钮由 28×28px 扩大为 36×36px，并增加悬停/聚焦反馈；
- 退出登录按钮最小高度提升至 36px；
- 来源头像与中文徽标字号由 10px 提升到 11px；
- 390px 视口复核没有新增横向溢出，资讯卡片、管理端仪表盘和侧栏布局保持稳定。

## 5. 已知边界

1. 本轮是本地真实数据与 Windows 无头浏览器回归，不替代生产 Linux、多浏览器和真实弱网测试。
2. 物理像素级截图用于发现布局问题，不建立大规模视觉快照基线，避免把动态内容变化误判为回归。
