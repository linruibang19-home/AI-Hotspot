# AI Hotspot 本地中间件与数据库连接指南

> 更新时间：2026-07-18。Docker Compose 是唯一标准运行方式；本文端口均为当前 `compose.yaml` 的本机映射。

## 1. 当前运行组件

| 组件 | 项目职责 | 容器内地址 | 本机入口 |
|---|---|---|---|
| Next.js Web | 用户端、智能端、管理端 | `web:3000` | `http://127.0.0.1:3000` |
| Nginx | 统一反向代理入口 | `nginx:80` | `http://127.0.0.1:8088` |
| Spring Boot Core API | 身份、权限、信源、内容、报告与管理业务 | `core-api:8080` | `http://127.0.0.1:8080` |
| FastAPI AI API | Provider 与 AI 能力入口 | `ai-api:8000` | `http://127.0.0.1:8000` |
| Python Worker | 采集、加工和异步任务消费者 | RabbitMQ/数据库内部连接 | 不对宿主机开放 |
| PostgreSQL 16 + pgvector | 业务主库、全文/向量能力 | `postgres:5432` | `127.0.0.1:15432` |
| Redis | Session、限流和短期状态 | `redis:6379` | `127.0.0.1:16379` |
| RabbitMQ | 可靠异步任务、重试和死信 | `rabbitmq:5672` | AMQP `5672`；管理页 `http://127.0.0.1:15672` |
| MinIO | 采集原件与对象存储 | `minio:9000` | API `9000`；控制台 `http://127.0.0.1:9001` |
| Mailpit | 开发邮件与验证码验收 | `mailpit:1025` | SMTP `1025`；UI `http://127.0.0.1:8025` |

## 2. Navicat 连接项目数据库

截图中已有的 `localhost:5432` 连接不是本项目 Compose 暴露端口。本项目为了避免与其他 PostgreSQL 冲突，默认使用：

| 字段 | 值 |
|---|---|
| 连接类型 | PostgreSQL |
| 主机 | `127.0.0.1` 或 `localhost` |
| 端口 | `15432` |
| 初始数据库 | `ai_hotspot` |
| 用户名 | 读取项目根目录 `.env` 的 `POSTGRES_USER` |
| 密码 | 读取项目根目录 `.env` 的 `POSTGRES_PASSWORD` |
| SSL | 本地开发关闭 |

不要把 `.env` 密码复制进文档或提交 Git。若 `.env` 没有覆盖，Compose 开发默认值是 `ai_hotspot`，正式环境必须更换。

连接后主要 Schema：

- `iam`：用户、角色、邀请码、邮箱验证码挑战；
- `source`：信源主体、Endpoint、抓取任务、原件和原始条目；
- `content`：内容、事件、关系、治理状态；
- `report`：日报/周报/月报及版本（后续 M6 完善）；
- `rag`：文档、切片、向量与研究会话（后续 M7 完善）；
- `subscription`、`delivery`：订阅和邮件投递（后续 M8 完善）；
- `agent`：Agent 运行与步骤（后续 M9 完善）；
- `messaging`：Outbox、Inbox、Dead Letter；
- `governance`：不可变审计和治理数据。

常用只读检查：

```sql
select version, description, success
from public.flyway_schema_history
order by installed_rank desc;

select status, count(*)
from source.source_endpoint
where catalog_kind = 'PRODUCTION' and status <> 'ARCHIVED'
group by status;

select id, email, display_name, status, created_at
from iam.user_account
order by created_at desc;
```

容器内执行 SQL：

```powershell
docker compose exec postgres psql -U ai_hotspot -d ai_hotspot
```

## 3. 认证与验证码数据

Flyway V009 新增 `iam.email_verification_challenge`。字段包含邮箱、用途、验证码摘要、有效期、消费时间、失败次数和请求 IP 摘要。系统不保存明文验证码；本地明文只存在于 Mailpit 邮件中。默认 10 分钟有效、最多错误 5 次，发送受 Redis 双维度限流。

普通用户流程：`/register` → 发送 REGISTER 验证码 → 验证并创建 USER → 建立 Redis Session。登录流程：`/login` → 发送 LOGIN 验证码 → 验证 → 建立 Session。管理员仍可使用 `.env` 中的引导邮箱/密码登录。

## 4. 中间件凭据与检查

- Redis 密码：`.env` 的 `REDIS_PASSWORD`；
- RabbitMQ：`.env` 的 `RABBITMQ_DEFAULT_USER/PASS/VHOST`；
- MinIO：`.env` 的 `MINIO_ROOT_USER/PASSWORD`；
- 引导管理员：`.env` 的 `BOOTSTRAP_ADMIN_EMAIL/PASSWORD`；
- 验证码摘要 pepper：`.env` 的 `EMAIL_CODE_PEPPER`，生产必须替换为长随机秘密。

健康检查：

```powershell
docker compose ps
docker compose logs core-api --tail 100
./scripts/Test-Email-Auth-Smoke.ps1
```

重置会删除本项目命名卷和全部本地数据，必须使用带确认的 `./scripts/Reset-Local.ps1`，不要手工删除其他项目容器或卷。
